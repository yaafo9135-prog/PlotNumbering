about=Plot Numbering is a QGIS plugin for assigning sequential numbers to polygon plots in cadastral, subdivision, surveying, and land-administration workflows. It provides directional ordering, grid ordering, interactive starting numbers, block-field support, and Automatic Block/Grid ordering for layouts with different block orientations. The numbering logic supports short-side-first progression and continuous numbering between adjacent blocks. The plugin provides a compact, resizable interface and is designed for compatibility with QGIS 3 and QGIS 4.
